# Раунд качества (+20 мин, только визуал существующего: рельеф/вода/надпись/кит)

Возвращён пост-стек оригинала (приёмы, код с нуля, MIT-notice): bloom 6 down/5 up (Karis fsDown0), half-res god-rays (W_RAYS, RAYN=34) + depth-aware blur (W_RBLUR), triplanar detail с domain-warp, экспозиция/тонмап ACES + saturation + dither (W_POST). GPU-запас потрачен с per-pass контролем.

## Defect-driven: root-cause → fix → статус (пиксели q3/q5/agy_pose*, вердикт критика v3)
1. Чёрные летающие slivers/пятна: root-cause = away-facing/backface почти чёрные (слабый ambient) + cull back. Fix: cull none, ambient floor + fill, фон без записи глубины. **Частично**: в q3/q5 летающих slivers нет; но pose6 остаётся чёрная backface-плита (критик: critical). НЕ закрыт полностью.
2. Stair-step кромки отсечения: root-cause = frustum margin 1.5 + drawdist 240. Fix: margin 4, drawdist 300, фон-haze 300, MSAA. **Частично**: критик всё ещё видит ступенчатые срезы на правых стенах.
3. Зеркальный тайлинг каустики: root-cause = периодический uv*2π. Fix: domain-warp в W_WATER + triplanar warp. **Частично**: критик видит повтор на левом поле.
4. Тусклая надпись: root-cause = низкий контраст на ярком дне. Fix: конформная тёмная подложка (heightfield-лист), эмиссия ×6, плотнее ракушки, bloom. **Частично**: автор читает «#вайбкодеры» (q3), слепой критик НЕ сертифицировал (подложку воспринимает как чёрное пятно, часть глифов размыта).
5. Иглы-плавники кита: root-cause = тонкие длинные tube. Fix: широкие короткие лопасти хвоста + плавники. **Частично**: критик видит хвост, но не целого кита (ракурс/тайминг).
6. Алиасинг/бандинг: MSAA-resolve + dither + тонмап. **Закрыто в основном**: бандинг у критика minor/borderline.

## Вердикт слепого критика (v3, только рендеры): **НЕ ПРОЙДЕН** — есть дефекты выше minor (critical чёрная плита pose6; major чёрные пятна/тайлинг/срезы/нечитаемая надпись). Итерации в рамках 20 мин не довели до сертификации.
