# LEDGER — часовой срез AGY_Aqua (разработчик: pi)

Предрегистрация порогов (из docs/evidence/benchmark_raw.json, оригинал 1080 Ti @2560×1440 High):
GPU avg ≤ 11, p99 ≤ 15, max ≤ 18 мс; бандл ≤ 110 КиБ (gzip ≤ 45). timestamp-query с первого кадра (начало=вода/конец=пост). zero-alloc числового состояния (F/UB преаллоцированы).

Харнес: docs/evidence/tools/{serve,cdp,bench}.mjs (копии в _harness/, serve смотрит в наш билд), Chrome 157, порт 9223, Emulation 2560×1440@1, dev.html клавиша B=60 с. Сборка node+esbuild (build.mjs, минификация JS+CSS+WGSL). GPU подтверждён chrome://gpu = GTX 1080 Ti (chrome_gpu.txt), не Remote Display/софт.

## Heap-проба (agy_heap.json)
Числовое состояние zero-alloc (F Float64Array(32), UB Float32Array(60) переиспользуются; анимации в VS).
НО WebGPU-объекты кадра (createCommandEncoder/getCurrentTexture().createView/finish) дают ~3 КБ/кадр (~170 КБ/с роста usedJSHeapSize между GC). Это раскрыто: «ноль аллокаций» относится к числовому состоянию, не к GPU-обёрткам (контракт ARCHITECTURE §0 это допускает). Абсолютный ноль JS-аллокаций НЕ достигнут.

## Финальные ворота TZ §5
1. 60-с пролёт под пороги: **PASS** (GPU 1.84/2.69/12.52 ≤ 11/15/18).
2. Слепой критик (только рендеры): **FAIL** — построено только 1 из 4 животных (кит); критик не назвал ни одного положительно в bench-ракурсах и не сертифицировал надпись. Ожидаемо для среза «один герой».
3. Отчёт о размере: **PASS** (43.9 КиБ / 19.1 КиБ gzip).

## Что не измерено / предположения
- Абсолютный FPS без vsync не снят (дисплей ~60 Гц); GPU-потолок выведен из GPU avg.
- Medium/Low не мерил.
- Слепой критик по bench-ракурсам не поймал кита (уплыл за 60 с) —identification кита подтверждён только авторским s5.png, не слепым критиком.
- Надпись: авторская читаемость есть, слепая сертификация — нет.
