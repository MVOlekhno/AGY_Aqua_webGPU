# AGY_Aqua_webGPU

Разбор [Noniv/abyssal-garden](https://github.com/Noniv/abyssal-garden) по коду и ТЗ на новый процедурный WebGPU-аквариум для Gemini Carbon.

- **[docs/ANALYSIS.md](docs/ANALYSIS.md)** — полный разбор оригинала на зафиксированном SHA `a596354` со ссылками файл:строка (228 ссылок, автопроверка).
- **[docs/REPORT.md](docs/REPORT.md)** — короткий отчёт: ответы на вопросы, замеры на GTX 1080 Ti, размер бандла, выводы.
- **[docs/TZ.md](docs/TZ.md)** — техническое задание (контракт для исполнителя).
- **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)** — архитектура нового аквариума.
- **[docs/evidence/](docs/evidence/)** — сырой лог бенчмарка, скриншоты 6 ракурсов, chrome://gpu, проверка ссылок, скрипты замеров.

Оригинал — MIT; цитаты кода в разборе приведены с указанием источника и лицензии. Сам аквариум в этом репозитории не разрабатывается — только разбор, репозиторий и ТЗ.
